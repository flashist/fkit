## Accepted residuals (shared, do-not-re-litigate)
- **Fence parsing is deliberately simple (R2)** — What: in `checkChangelog()` a line starting with ``` or ~~~ toggles fence mode whatever the delimiter kind or length, so a nested or mixed fence can flip state early and a `## ` line inside the inner block is read as a heading; a UTF-8 BOM before a first-line `## Unreleased` is refused as "no `## Unreleased` heading"; an HTML comment holding a `## Unreleased` line is refused as a duplicate. · Why (structural): `plan.md` § 2 chose a small, dependency-free parser for the release path; CommonMark-accurate fences (same character, closer at least as long as the opener, indentation rules) or BOM / comment handling add code for shapes no CHANGELOG here uses. The only unsafe outcome — an empty `## Unreleased` releasing because a mis-read `## v<target>` triggered the recovery skip — is closed on bumping runs by R1, so it stays reachable only on a `--no-bump` run; the BOM and HTML-comment cases fail safe (refused). Rejected: full CommonMark fence matching; BOM stripping; comment-aware scanning. **Owner ruling 2026-10-05** (`AskUserQuestion`, fkit-lead session): "Accept as known limit" — "Record it as a rare limit of the simple reader, re-raised only if a real CHANGELOG hits it. R1 is fixed either way." · Re-raise only if: a real `CHANGELOG.md` (this repo's or a consuming project's) hits one of these shapes — a nested/mixed fence, a BOM, or a commented-out `## Unreleased` — and it changes or blocks a release.
