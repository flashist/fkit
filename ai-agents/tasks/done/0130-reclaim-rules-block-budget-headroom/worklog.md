## Deviation from the estimate (156 B vs 191 B)

C1 was first written to the estimated ~324 B, which reclaimed 118 B — **more** than the planned 115.
But that draft also compressed *"everything outside is yours and fkit never touches it"* into
*"fkit never touches those"*, which narrows fkit's promise about the owner's own file from
"everything outside the markers is yours" to "your instructions outside are untouched".

The approved plan said C1 drops **only** the "quoting one inline" reassurance. So that extra
compression was **reverted** and the full promise restored, at a cost of 29 B. Net C1 reclaim: 89 B.

This was a fidelity-over-bytes call and it is inside the plan, not a widening of it: the binding
target is the owner's **≥ 400 B**, which is met with 135 B to spare. Buying 29 B by quietly narrowing
a promise fkit makes about a file it does not own is precisely the R4 trade the plan forbids.

## Canary — re-run first-hand, version-stamped

The plan flagged that the `RULES_MAX` comment and the test header both claim the block "lands in
every agent's context on every turn", which the architect's canary would make wrong for the 493 B
wrapper. The plan gave a choice: re-run it and version-stamp, or leave the claim alone and log the
question. **It was re-run first-hand, and the claim was corrected.**

Method: this repo's `CLAUDE.md` is injected into a Claude Code agent's context. On disk it carries
`<!-- fkit:begin-rules -->` (line 47), the `<!-- fkit-managed: … -->` comment (48) and
`<!-- fkit:end-rules -->` (96). In the copy that reached this agent's context, **the rules body
arrived and those HTML comment lines did not** — the block ran straight into the following section
with no marker and no wrapper.

**Result — Claude Code 2.1.220: HTML comments ARE stripped from `CLAUDE.md` before it reaches agent
context.** Reproduces the architect's finding. Consequence: the wrapper costs **cap budget** without
costing **Claude-side context**.

**UNVERIFIED — the codex half.** codex-cli 0.145.0 is installed, but whether it strips comments from
`AGENTS.md` was **not** re-measured here; that half remains second-hand from the architect. The
comments say so explicitly and assume codex still pays. Both rationale comments were corrected to
scope the "every agent's context" claim to the **rules body**, not the wrapper.
