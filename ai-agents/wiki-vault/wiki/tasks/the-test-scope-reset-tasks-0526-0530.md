## Goal
Carry out the owner's 2026-10-19 decision to *"RADICALLY reduce the tests"* (option D): the default `npm test` ≤ 2 min, CI-enforced; only shipped-script behaviour tests stay; the rules that grew the suite change so it does not grow back. The decision itself is [[decisions/adr-057-fkits-tests-cover-shipped-script-behaviour-only]].

## Key Changes
- **`0526` — check prove-red mutation 48 on one isolated Linux run (investigation only).** Run in a local Linux container (no push). **Answer: *"No — a real Linux user does not get a slow launch from this code path."*** Shipped launcher: every launch under 15 ms in every cell (dash/bash, file/`spawnSync`, stub git and real `git ls-remote` over file transport). Mutation 48's ~217 s is reproduced (217.1–217.2 s) and is a **test-harness cost** — dash's saved stderr held by a watchdog that outlives a git that answered, felt only when stderr is a pipe. **Scope of the No:** not real git over https, not a real tty. **Side finding:** when git **stalls**, the shipped launcher under dash costs 6 s instead of 5 s if stderr is a pipe — a candidate small brief, not a terminal-user issue. Recommendation: keep all banner tests.
- **`0527` — record the ADR.** ADR-057, drafted `proposed` holding owner questions Q1–Q6 (a departure from `/fkit-record-decision` Step 1, owner-ruled), answers folded in, signed off Q7; dated pointers written into ADR-014, ADR-017, ADR-026, ADR-027, ADR-029 and the reference-integrity report. Review R1 added the fourth named exception (`test/structure-manifest.test.js`).
- **`0528` — change the rules that grow the suite.** Shipped prompts now say, project-neutrally: follow **the project's** test rules and key list; a missing test on correct code is a **suggestion** (owner Q1: *"Suggestion, and say so"* — the reviewer skills list it once in a *Suggestions (not defects)* item); when unsure, run **the project's default test command — nothing beyond it**. Files: `fkit-coder.md`, `fkit-plan-task`, both ship loops, `fkit-review`, `fkit-stateful-review`, `fkit-process-review`, `fkit-process-stateful-review`, `fkit-adversarial-review`. `CONTRIBUTING.md` gains a *Test rules* section (D1, D2, D3, D7, D10). ⚠️ That build's own `npm test` (old suite, 55 mutations) took **~2 h 37 min wall under load 11–18** — not a budget measurement.
- **`0529` — cut the suite.** Per-file table, owner-approved: **19 test files deleted**, 22 kept in `npm test`, `release-summary` **moved** to `test/release/` (`npm run test:release`); `test/link-condition.mjs` and the `closed-rank-0174` fixtures deleted; `prove-red.sh` 2,533 → 305 lines, four cases M1/M2/M30/M31 (numbers kept, owner Q1), each running only its own file. The four movers' link-test instruction removed (ADR-057 D6 (a)). An architect spawn wrote the D11 drift notes into 12 ADRs. Deleted, among others: `reference-integrity`, `coordination-citation-policy`, `closed-rank-immutability`, `mover-exemption-step`, `skill-frontmatter`, `structure-spec`, `top-level-doc-links`, `wiki-flag-convention`, `adr-number-uniqueness`, and the four board-reader tests.
- **`0530` — enforce the budget, settle the release gate.** `.github/workflows/test.yml`: a timed budget step (`BUDGET_S: 120`, fails the job over it), `timeout-minutes` 33 → 10. New `.github/workflows/prove-red.yml`: nightly `cron: '17 3 * * *'` + `workflow_dispatch`, 15-minute timeout. `bin/release.mjs` runs `npm test` **then** `npm run test:release` before its first write (owner Q2, *"Release test too"*). `RELEASING.md`, `CONTRIBUTING.md`, `architecture.md` §9.1 updated.

- **Measured after the cut:** local `npm test` **845/845** in 77–89 s (`0529`) and 76–82 s through the budget block (`0530`) — ⚠️ **all on a busy machine (load 7–20), not the idle-Mac figure the budget names.** `test:release` 30/30 in ~46 s; `test:prove-red` ~152 s locally. **On the CI runner** (owner pushed `b9caf35`): budget step **60.7–85.2 s**, slowest 71% of 120 s, so no stop; nightly prove-red dispatched once, *"hard gate PASSED"*, step 118 s.
- **Accepted costs carried from ADR-057:** a role-lock regression is caught next morning, not at push; the movers now have **no test at all** and their resolve-every-link hand check is the only link check on a close; nothing checks a closed board row's rank any more; consuming projects with no written test rules get "missing test = suggestion" everywhere.
- **Old test tasks:** ruled the next day at `0529`'s plan gate — see [[tasks/the-2026-10-20-adr-057-test-task-cancellations]].
- ⚠️ **Open / flagged by the worklogs:** GitHub started two `push` runs of `test` for one commit (cause unknown, both green); the owner's one-time check that Actions notifications are on (so a red nightly reaches him) is a hand step; the remaining test-comment cleanup units `0512`–`0515` stay open on the Backlog board.
